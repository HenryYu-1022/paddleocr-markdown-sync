# README 项目目的与 RAG 建议文案设计

## 目标

在 README 开头增加独立的“项目目的”章节，说明本项目不仅用于把 PDF 文献库持续转换为 Markdown，也是在为后续基于文献库的 RAG 检索和个人知识库建设准备可读取、可索引的文本来源。

## 文案范围

- 说明 PDF 经 PaddleOCR 在线 API 转换后，可作为 RAG 的文档输入。
- 建议用户在转换完成后，对 Markdown 建立索引，以构建基于个人文献库的个体知识库。
- 强调应保留来源路径和文档边界，方便回答结果回溯到原始论文。
- 明确 RAG 的切分、向量化、索引和问答系统不属于本项目当前功能范围，避免让用户误以为本工具已经内置 RAG。

## 放置位置

章节放在 README 首段介绍之后、“项目支持”之前，使读者先理解项目用途，再阅读功能清单与配置步骤。

## 验收标准

- README 明确出现对后续 Markdown RAG 的建议。
- README 明确表达建立基于个人文献库的个体知识库这一用途。
- 不声称项目已实现 RAG。
- 现有安装、API 配置、正文与 SI 独立处理等说明保持不变。
